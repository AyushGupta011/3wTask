# 3W Social App Backend

This is the backend API for the 3W Social App, built with Node.js, Express, and MongoDB.

## Requirements

- Node.js
- MongoDB (Atlas or local)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   Copy `.env.example` to `.env` and fill in your details:
   ```bash
   cp .env.example .env
   ```

3. Start the server:
   ```bash
   # Development mode
   npm run dev
   
   # Production mode
   npm start
   ```

The API will be running at `http://localhost:5000`.
